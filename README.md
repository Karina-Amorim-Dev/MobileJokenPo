## ✊ MobileJokenPo

«Um jogo mobile de Pedra, Papel e Tesoura, desenvolvido para Android com Kotlin e Java utilizando o Android Studio.»

O MobileJokenPo é um projeto desenvolvido para praticar conceitos de programação e desenvolvimento de aplicações Android, combinando uma interface simples com a lógica tradicional do jogo JokenPo.

O jogador escolhe uma opção e disputa uma rodada contra o computador. Ao final, o aplicativo identifica automaticamente o resultado: vitória, derrota ou empate.

---

## 🎮 Sobre o projeto

O projeto consiste em uma versão mobile do tradicional jogo Pedra, Papel e Tesoura.

A aplicação foi desenvolvida com foco em uma experiência simples e intuitiva, permitindo que o usuário interaja diretamente com as opções disponíveis na tela.

# Como jogar?

O jogador escolhe uma das três opções:

- ✊ Pedra
- 🖐️ Papel
- ✌️ Tesoura

O computador realiza sua própria escolha e o aplicativo compara as duas jogadas para determinar o resultado.

---

## ✨ Funcionalidades

- 🎮 Escolha entre Pedra, Papel ou Tesoura
- 🤖 Jogada automática do computador
- 🏆 Identificação de vitória
- 😔 Identificação de derrota
- 🤝 Identificação de empate
- 📱 Interface para dispositivos Android
- ⚡ Resultado apresentado diretamente na tela

«O projeto não possui sistema de pontuação ou placar. Cada escolha representa uma nova rodada.»

## 🚀 Como executar

Pré-requisitos

Para executar o projeto, é necessário ter:

- "Android Studio" (https://developer.android.com/studio)
- Android SDK
- JDK compatível com a configuração do projeto
- Um emulador Android ou dispositivo físico para execução

# Clone o repositório

git clone https://github.com/Karina-Amorim-Dev/MobileJokenPo.git

Abra o projeto

1. Abra o Android Studio.
2. Selecione Open.
3. Escolha a pasta "MobileJokenPo".
4. Aguarde a sincronização do Gradle.
5. Selecione um emulador ou dispositivo Android.
6. Clique em Run ▶ para executar a aplicação.
